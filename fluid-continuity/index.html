Morph States & Shared Layouts Without Distortion

Ensure continuous visual flow across container changes, shared element transitions, optical icon morphs, and asymmetric exit reflows without glyph stretching or GPU paint thrashing.

Child text locks position; exit snaps in 120ms (0.5x enter) with critically damped spring.

Crisp text morph · 120ms exit

Why this works

Lock text aspect ratio during layout morphs and make exit animations 2x faster than entrances.

|scaleX - scaleY| <= 0.04 · Exit Duration <= 0.6x Enter

Unconstrained layout morphs warp font glyph aspect ratios during container expansion, while sluggish dismissals trap user attention. Enforce uniform scale projection (|scaleX - scaleY| <= 0.04) and make exit animations 2x faster than entrances.

Continuous Fluid Interactions & State Morphing

Interactive Drills
  1. Aspect-Ratio Scale Invariance: When expanding a small card (W1/H1) into a large details view (W2/H2), container scale factors diverge (scaleX != scaleY). Applying this matrix transform directly to text causes visible distortion. Text children must decouple via layout="position" to maintain an isotropic 1:1 scale (|scaleX - scaleY| <= 0.04).
  2. Optical Blur Bridging vs. Geometric Rotation: When two icons share topological symmetry (such as + and ×, or chevrons), state changes should execute via pure geometric rotation (transform: rotate(45deg)) with zero GPU rasterization cost. For topologically distinct icons (such as Copy and Check), an optical blur bridge (blur(4px) + critically damped spring zeta = 1.0) provides perceptual continuity without raster stalls.
  3. Asymmetric Exit Velocity: When users dismiss a surface (modal, sheet, toast, or list row), their cognitive task is complete. Lingering exits waste attention. Systems must enforce an asymmetric exit ratio: T_exit = round(0.5 * T_enter) <= 200ms
  4. Compositor Clip-Path Continuity: Sliding segmented indicators and progress indicators must utilize compositor-accelerated clip-path: inset() rather than DOM restructuring to achieve seamless inverted-color reveals.

Remediation

Protect child typography inside morphing containers and enforce asymmetric exit timings:

/* Good: Text protected with layout="position", asymmetric exit duration */
<motion.div layout layoutId="card-container" className="card">
  <motion.h3 layout="position" className="text-lg font-bold">
    Live Cluster Metrics
  </motion.h3>
  <AnimatePresence>
    {isOpen && (
      <motion.div
        initial={{ opacity: 0 }}
        animate={{ opacity: 1, transition: { duration: 0.24 } }}
        exit={{ opacity: 0, transition: { duration: 0.12 } }}
      >
        <p>Expanded telemetric details</p>
      </motion.div>
    )}
  </AnimatePresence>
</motion.div>

What to Look For & How the Linter Fixes It

Visual signs in your UI and how the verifier guides your coding agent.

Visual Symptom
  • Text stretches or warps briefly when a card expands into a modal or details view.
  • Swapping two icons (e.g. Copy to Check) looks mushy, jumpy, or twitches container width.
  • Dismissing a toast or modal feels sluggish because exit transitions take as long as entrance transitions.
  • Deleting a row makes surrounding sibling items snap violently instead of collapsing smoothly.
Linter Check
  • Blur filter > 12px on surfaces > 6400px² or across >3 siblings.
  • Non-uniform scale matrix (|scaleX - scaleY| > 0.04) warping text glyphs.
  • Transition duration > 200ms on exiting or closed state elements.
