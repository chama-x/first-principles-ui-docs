Stage 5: Physical Ergonomics

Delete Motion on High-Frequency & Keyboard Actions

Eliminate animation fatigue by scaling duration inversely with interaction frequency: instant keyboard shortcuts, warm tooltip handoffs, capped list staggers, and optimistic updates.

Full reference & code

Everyday utility actions should never demand attention with flashy decorative animations. Spend novelty budgets exclusively on celebratory milestone events, keeping high-frequency repetitive tasks instant (< 100ms).

Frequency Delays & Optimistic UI

Interactive Drills

Animation has a novelty half-life. A 400ms entrance that delights on day 1 becomes an infuriating tax by day 30 when repeated 200 times a day.

The Frequency-Duration Inverse Law

LAW_29_HIGH_FREQ_MOTION_TAX states that animation duration must scale inversely with interaction frequency:

  1. High-Frequency Actions (f >= 100 / day): Duration must be 0ms (instantaneous).
  2. Keyboard-Triggered Actions: When an action is invoked via a keyboard shortcut (e.g. Cmd+K, arrow keys, Esc), users operate in cognitive command mode. Motion duration must not exceed 100ms.
  3. Staggered Entrances: Cumulative stagger delay across any list or grid must be capped at sum(delta_t) <= 300ms.

What to Look For & How the Linter Fixes It

Visual signs in your UI and how the verifier guides your coding agent.

Visual Symptom
  • Power users feel the interface is sluggish despite 60fps rendering because transitions delay actions.
  • Tapping keyboard shortcuts (e.g. Cmd+K or arrow keys) plays slow fade-in animations.
  • Hovering across a row of toolbar icons causes each tooltip to animate slowly from scratch.
  • Loading spinners flash for 40ms on fast network requests, creating visual jitter.
Linter Check
  • Keyboard-triggered modal, palette, or menu transition duration > 100ms.
  • Staggered list item delay sum exceeds 300ms.
  • High-frequency action (f >= 100/day) has motion duration > 0ms.

Agent Prompts & Oracles

Plug directly into Claude, Codex, or terminal execution.

Design an efficient enterprise toolbar and data table. Follow the Frequency-Duration Inverse Law: make keyboard-invoked commands instant (0ms transition), cap list staggers at 300ms total, implement warm tooltip handoffs, and use optimistic UI for inline toggles.
