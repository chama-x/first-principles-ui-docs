Perceptual Chart Geometry & Dynamics

Interactive Drills

Data visualization is an exercise in perceptual truth. When software distorts scales, crops baselines, or maps values incorrectly to geometric primitives, it deceives the reader.

The Cleveland & McGill Baseline Law

The human visual system evaluates bar charts by comparing the length of bars relative to a shared baseline. If a linear bar chart's baseline starts at 80 instead of 0, a 5% difference between 82 and 92 is magnified into a 400% visual height difference.

LAW_20_ZERO_BASELINE mandates that:

Any linear bar chart representing absolute physical quantities must anchor its value scale at zero ($y = 0$). Logarithmic scales on bar charts are strictly prohibited.

Stevens's Power Law for Bubble Areas

When visualizing quantities with circles or bubbles, humans perceive physical area ($A = \pi r^2$), not linear radius ($r$). Scaling radius linearly ($r = k \cdot v$) squares the perceptual ratio: a 2x metric difference produces a 4x visual area difference.

LAW_21_BUBBLE_AREA mandates square-root radius mapping:

r = k * sqrt(v)

Fritsch–Carlson Monotone Splines vs. Catmull-Rom Overshoot

Naive spline interpolation (such as standard Catmull-Rom splines) frequently overshoots local extrema, dipping below zero or fabricating peaks that never existed in the underlying sampled data.

What to Look For & How the Linter Fixes It

Visual signs in your UI and how the verifier guides your coding agent.

Visual Symptom
  • A 4% difference between metrics appears as a massive visual chasm due to a truncated axis.
  • Bubble chart circles look 4x larger for a metric that is only 2x greater.
  • Cubic splines overshoot below zero or create impossible peaks between discrete data points.
  • Chart axis tick labels collide and overlap on tablet or mobile viewports.
Linter Check
  • Linear bar chart y-axis does not include y=0 (truncation error).
  • Bubble radius scaled linearly r = k*v instead of Stevens area law r = k*sqrt(v).
  • SVG bounding box intersection on data labels.
  • Spline overshoot creating non-monotonic artifacts between sample nodes.

Agent Prompts & Oracles

Plug directly into Claude, Codex, or terminal execution.

Build a responsive data dashboard with bar charts, line graphs, and metric trends. Enforce Cleveland-McGill zero-baseline standards for all bar series, use Fritsch-Carlson monotone cubic splines for smooth line series, and ensure bubble markers scale radius by square root of value.
