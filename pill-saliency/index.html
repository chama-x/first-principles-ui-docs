Optical Enclosure on Media & Avatars

Interactive Drills

Status pills, tags, and badge chips convey critical state in application dashboards. On dark surfaces, low-contrast pills frequently dissolve into the surrounding card canvas, rendering tags illegible as distinct interactive units.

The substrate foundation is Figure–Ground Segregation:

  1. Boundary Enclosure: Human vision requires a clear closed contour to distinguish an entity as a distinct object ("figure") rather than a continuous texture of the underlying surface ("ground").
  2. Dark Mode Lightness Compression: In dark mode, luminance perception is compressed in lower tiers. A step 3 background on step 1 canvas often has less than 4% lightness difference (ΔL < 0.04), causing boundaries to vanish under ambient room glare.

The same boundary saliency rule applies to circular avatars and media thumbnails on dark cards. An avatar with dark edge pixels blurs into the dark canvas unless bound by a 1px inner hairline stroke:

Remediation

Pair Step 3 fills with a 1px solid Step 6 hairline border on dark surfaces:

// Right: High-saliency dark status pill
<span className="inline-flex items-center rounded-full border border-border/80 bg-muted/50 px-2.5 py-0.5 text-xs font-medium text-foreground">
  Active Status
</span>
Under the Hood: Mathematical Formula & Verifier SourceOptional Deep Dive

The verifier isolates status pills and computes the perceptual boundary contrast:

Luminance Separation Floor: |L_pill - L_surface| >= 0.06 OR border-width >= 1px with alpha >= 0.15

View Deterministic Verifier Source (check-ui-math.mjs)

// Evaluated by src/rules/pill-saliency.mjs
const deltaL = Math.abs(pillOklch.L - surfaceOklch.L);
const hasBorder = borderRgba.a >= 0.15 && borderWidth >= 1;

if (deltaL < 0.06 && !hasBorder) {
  ctx.report("LAW_07_PILL_BOUNDARY_SALIENCY", {
    property: "pill_border_contrast",
    computed: deltaL,
    threshold: 0.06,
  });
}

What to Look For & How the Linter Fixes It

Visual signs in your UI and how the verifier guides your coding agent.

Visual Symptom
  • Status badges and filter chips blend into dark cards and become invisible under ambient lighting.
  • User avatars with dark backgrounds blur into dark card headers.
  • Tag boundaries cannot be distinguished unless hovered.
Linter Check
  • Dark surface (L < 0.35) where |L_pill - L_surface| < 0.06 without a 1px border.

Agent Prompts & Oracles
